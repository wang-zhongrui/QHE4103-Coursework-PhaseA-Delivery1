# QHE4103 Online Car Sale - Phase A (Delivery 1)

## 📌 Project Overview
This repository contains the source code for Delivery 1 of the QHE4103 Fundamentals of Web Technology coursework. The objective is to design and implement a responsive front-end website for a fictitious Online Car Sale company.
